## Примеры использования:
1. В пакете *'config'* расположены основные настройки проекта Django.
2. В приложении *'lms'* расположены основные элементы приложения для онлайн-обучения 'lms'.
3. В приложении *'lms'* создан модуль *'urls'* для настройки маршрутизации проекта.
4. В приложении *'lms'* и модуле *'views'* определён вьюсет 'CourseViewSet' для работы с сущностью "Курс".
5. В приложении *'lms'* и модуле *'views'* определены дженерики для работы с сущностью "Урок".
6. В приложении *'lms'* и модуле *'models'* определёны модели данных для Курса и Урока.
7. В приложении *'users'* расположены основные конфигурации приложения пользователя. Сформированы модели, сериализатор, вьюсеты и маршрутизация.
8. В приложении *'users'* добавлена модель "Платежи". Сформированы сериализатор, дженерики и маршрутизация для данной модели.
9. Добавлены настройки авторизации (JWT) и прав доступа. Все эндпоинты закрыты авторизацией.
10. Создана группа модераторов (сохранена фикстура "users.fixture.groups.json). Для группы модераторов описаны права работы с уроками (нельзя создавать и удалять).
11. Описаны права доступа для владельцев объекта (просмотре, редактирование и удаление только своих объектов).
12. В приложении *'lms'* добавлен файлы 'validators.py', 'paginations.py'. Сформированы и описаны валидатор для поля 'video_link', а также пагинатор для списка курсов и уроков.
13. В приложении *'lms'* создана модель для подписок. Добавлены сериализаторы и контроллера для установки подписки пользователя и на удаление подписки у пользователя.
14. Добавлена API документация проекта.
15. Добавлена интеграция сервиса stripe для оплаты курсов.
16. В проект добавлены настройки Celery. Созданы задачи для ассинхронной рассылки писем подписанным пользователям, при обновлении материалов курса.
17. В проект добавлена периодическая задача, при которой пользователи, не заходившие более месяца блокируются и становятся неактивными.
