## 📦 Установка и запуск

### 1. Клонирование репозитория
```
git clone https://github.com/soulbratan/SkripnikovOV_CourseProj_5_SkyPro_DjangoREST.git
```
### 2. Установка зависимостей
```
 poetry update
```
### 3. Настройка переменных окружения
 *Создайте файл ".env" и заполните по аналогии с ".env.sample"*

### 4. Настройка БД
```
 python manage.py migrate
 
 python manage.py csu
```

### 5. Запустите сервер
```
 python manage.py runserver
```
### 6. Запустите CELERY worker и beat
```
 celery -A config worker --loglevel=info --pool=solo
 
 celery -A config beat --loglevel=info
```

### ИЛИ. Запустите через DOCKER
```
 # Сборка и запуск контейнеров
   docker-compose up --build -d
 
 # Просмотр логов
   docker-compose logs -f

 # Остановка
   docker-compose down
```

## 📦 API Эндпоинты

### Аутентификация
- **POST /users/login/** - вход (получение JWT токенов)
- **POST /users/login/refresh/** - обновление access токена
- **POST /users/register/** - - регистрация нового пользователя

### Пользователи
- **GET /users/** - список пользователей (публичные данные)
- **GET /users/{id}/** - профиль пользователя
- **PATCH /users/{id}/update/** - обновление профиля
- **DELETE /users/{id}/delete/** - удаление профиля

### Привычки
- **GET /habtracker/** - список привычек текущего пользователя
- **POST /habtracker/** - создание новой привычки
- **GET /habtracker/{id}/** - детали привычки
- **PATCH /habtracker/{id}/ ** - обновление привычки
- **DELETE /habtracker/{id}/** - удаление привычки
- **GET /habtracker/public/** - список публичных привычек
- **POST /habtracker/{id}/complete/** - отметка выполнения привычки

### Документация
- **GET /swagger/** - Swagger UI документация
- **GET /redoc/** - ReDoc документация


## 📦 Модели данных

### User (Пользователь)
- **email** - уникальный email (используется для входа)
- **first_name, last_name** - имя и фамилия
- **phone** - телефон
- **tg_id** - chat ID Telegram для уведомлений
- **avatar** - аватар пользователя

### Habit (Привычка)
- **user** - владелец привычки
- **place** - место выполнения
- **time** - время выполнения
- **action** - действие привычки
- **is_pleasant** - признак приятной привычки
- **related_habit** - связанная привычка
- **frequency** - периодичность (1-7 дней)
- **reward** - вознаграждение
- **duration** - время на выполнение (≤120 секунд)
- **is_public** - признак публичности
- **start_date** - дата начала привычки

### HabitCompletion (Выполнение привычки)
- **habit** - связанная привычка
- **completed_at** - время выполнения
- **is_successful** - успешность выполнения

## ⚡ Валидация привычек

### Бизнес-правила

1. **❌ Нельзя одновременно указывать связанную привычку и вознаграждение**
   - Можно выбрать только один вариант: либо связанную привычку, либо вознаграждение
   - Оба поля не могут быть заполнены одновременно

2. **⏱ Время выполнения должно быть не больше 120 секунд**
   - Максимальная продолжительность привычки - 2 минуты
   - Проверка поля `duration`

3. **🔗 В связанные привычки могут попадать только привычки с признаком приятной привычки**
   - Поле `related_habit` может ссылаться только на привычки с `is_pleasant=True`
   - Нельзя связывать полезные привычки между собой

4. **😊 У приятной привычки не может быть вознаграждения или связанной привычки**
   - Если `is_pleasant=True`, то поля `reward` и `related_habit` должны быть пустыми
   - Приятные привычки являются конечными действиями

5. **📅 Нельзя выполнять привычку реже, чем 1 раз в 7 дней**
   - Поле `frequency` должно быть в диапазоне от 1 до 7 дней
   - Привычка должна повторяться минимум раз в неделю

6. **🔄 Защита от циклических зависимостей**
   - Предотвращение бесконечных циклов в связанных привычках
   - Привычка A → Привычка B → Привычка A (запрещено)

7. **👤 Нельзя ссылаться на чужие привычки**
   - Связанная привычка должна принадлежать тому же пользователю
   - Защита от использования чужих привычек как связанных

## 🔔 Задачи Celery

### Периодические задачи

#### 📧 **send_habit_reminders** - Отправка напоминаний
**Назначение:** Отправка Telegram уведомлений за 5 минут до времени выполнения привычки

**Расписание:** Запускается каждую минуту
```
python
"send-habit-reminders": {
    "task": "habtracker.tasks.send_habit_reminders",
    "schedule": timedelta(minutes=1),
}
```
